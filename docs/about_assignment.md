1. 이상탐지 분석용 데이터 선정

   - 불균형이 극대로 심한 데이터를 선정하면 됨

   - 일부 분류문제로 되어 있는 데이터에 대해 불균형 문제상황을 만들고 이상탐지를 정할 수도 있음

2. 이상탐지 알고리즘 비교실험(comparative study)

   - 학습한 알고리즘(KDE, GMM, LOF, PCA, AE 등) + 본인이 새로 찾은 이상탐지 알고리즘 +1을 추가 비교 실험 진행

   - 비교실험 결과를 이상탐지 평가지표로 산출 (수업에서 다룬 지표 또는 일반적인 분류 평가 지표 모두 활용)

   - 특히 본인이 추가 선택한 이상탐지 알고리즘에 대해 강건성을 보여주기 위해 ablation studies 수행

3. 이상탐지 실험에 대한 2단짜리 2 pages 분량의 short report 작성

   - 내용은 아래사항 필수 포함

      1. 초록

      2. 서론 - 데이터 내 심각한 불균형 설명

      3. 이상탐지를 적용하려는 데이터 EDA 

         (데이터는 변수몇개, 샘플 몇개, 각 변수는 어떠한 분포를 따르고, 결측치/이상치가 얼마나 포함되며,, 등등)

      4. 본인이 선정한 새로운 이상탐지 알고리즘 간략 소개 (알고리즘 기술, 수식, 그림 설명 등)

      5. 실험 결과

      6. 전체 실험에 대한 총평 및 결론
